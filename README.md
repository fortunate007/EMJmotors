# EMJ Motors Ltd — Full Dealership Platform (v4.0)

Multi-page Express site with sidebar navigation, top ticker,
full inventory + offers management, JSON-file database, and admin
dashboard. Light/warm theme.

## Run
    npm install && npm start

Then open the URL shown and browse freely.

## Pages
/                Home (hero + filters + makes + stock + services)
/products        Full stock listing with filters
/about           Creative About page (vision, mission, what a dealer should do)
/how-to-buy      6-step buying guide
/offers          Special Offers (managed via admin)
/faq             Accordion FAQ
/contact         Contact info + WhatsApp form + map
/qisj            QISJ Mileage Verification info
/login           Login / Register (placeholder)
/admin           Admin dashboard (cars + offers + settings)

## Features
- Top ticker with rotating contact info + "We Make Your Dreams Drive"
- Left-aligned hamburger opening a slide-out sidebar menu
- Light cream/white theme with gold accents
- Full backend + frontend for Special Offers (upload images, toggle active, order)
- Cars inventory management (add/edit/delete/toggle sold)
- Site settings editor (contact, colours, about text)
- WhatsApp float button everywhere
- Brand-new / foreign used / locally used / import-on-order all supported
